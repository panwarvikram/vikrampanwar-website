Formatting
Stamp-paper top margin (plaint only)

If the plaint is printed on court-fee/stamp paper, a 5-inch top space is reserved so text clears the printed stamp. Enter how many pages the plaint runs to, then tick the plaint pages that will be on stamp paper. This is applied to the plaint only — never to the affidavit, list or index.

Note: a generated file can't target an exact interior page reliably, so ticking page 1 only reserves the first plaint page; ticking any later page reserves the top of every plaint page (in Word). The affidavit, list and index are never affected.

Examination-in-chief affidavit (optional)

Prepared from the same case details, on its own page(s), with documents shown as blank "Ex. ___" marks to fill in court. It is never included in the index.
